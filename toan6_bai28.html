📘 Bài 28: Số thập phân

📖 1. Phân số thập phân và số thập phân

📌 Phân số thập phân

Phân số thập phân là phân số có mẫu số là lũy thừa của 10.

Ví dụ:

1/10 ; 15/100 ; 247/1000 ; 8/10000

đều là các phân số thập phân.

Các phân số:

-3/10 ; -25/100 ; -7/1000

là các phân số thập phân âm.

Các phân số:

3/10 ; 25/100 ; 7/1000

là các phân số thập phân dương.

📌 Số thập phân

Ta viết:

-14/10 = -1,4

Đọc là: âm một phẩy bốn.

-25/100 = -0,25

Đọc là: âm không phẩy hai mươi lăm.

1/10 = 0,1

Đọc là: không phẩy một.

Các số:

-0,3 ; -1,6 ; -3,76

là các số thập phân âm.

Các số:

0,17 ; 1,89 ; 3,15

là các số thập phân dương.

📌 Tính chất của số thập phân

  • Phần bên trái dấu phẩy là phần nguyên.
  • Phần bên phải dấu phẩy là phần thập phân.
  • Thêm chữ số 0 vào bên phải phần thập phân thì giá trị số không đổi.

21,45 = 21,450 = 21,4500

  • Hai số có tổng bằng 0 gọi là hai số đối nhau.

1,7 và -1,7 là hai số đối nhau.

📌 Đổi số thập phân sang phân số

Bước 1: Đếm số chữ số bên phải dấu phẩy.

Bước 2: Bỏ dấu phẩy và viết số đó ở tử.

Bước 3: Viết mẫu là 10, 100, 1000,...

Bước 4: Rút gọn nếu có thể.

🔍 Ví dụ 1

Đổi 0,14 sang phân số.

0,14 = 14/100

= 7/50

📌 Đổi phân số sang số thập phân

Bước 1: Đưa phân số về dạng phân số thập phân.

Bước 2: Đặt dấu phẩy thích hợp ở tử số.

🔍 Ví dụ 2

Đổi 16/10 sang số thập phân.

16/10 = 1,6

📖 2. So sánh hai số thập phân

📌 So sánh hai số thập phân dương

  • So sánh phần nguyên trước.
  • Nếu phần nguyên bằng nhau thì so sánh phần thập phân từ trái sang phải.

🔍 Ví dụ 3

So sánh:

3,56 và 7,37

Vì:

3 < 7

nên:

3,56 < 7,37

So sánh:

4,25 và 4,35

Phần nguyên đều bằng 4.

So sánh hàng phần mười:

2 < 3

nên:

4,25 < 4,35

📌 So sánh hai số thập phân âm

Nếu a và b là hai số thập phân dương:

a > b

thì:

-a < -b

Số thập phân âm luôn nhỏ hơn 0.

Số thập phân dương luôn lớn hơn 0.

🔍 Ví dụ 4

So sánh:

0,745 và -1,234

Vì:

0,745 là số dương

-1,234 là số âm

nên:

0,745 > -1,234

So sánh:

-2,13 và -3,12

Vì:

2,13 < 3,12

nên:

-2,13 > -3,12

📝 Ghi nhớ

  • Phân số thập phân có mẫu là 10, 100, 1000,...
  • Số thập phân gồm phần nguyên và phần thập phân.
  • Có thể đổi qua lại giữa số thập phân và phân số.
  • Thêm số 0 ở cuối phần thập phân không làm thay đổi giá trị số.
  • Khi so sánh số thập phân, so sánh phần nguyên trước rồi đến phần thập phân.
  • Số dương lớn hơn số âm.
  • Trong hai số âm, số có giá trị tuyệt đối nhỏ hơn thì lớn hơn.
