📘 Bài 8: Tổng và hiệu hai lập phương

📖 1. Tổng hai lập phương

Với hai số a và b bất kì:

(a + b)(a² − ab + b²) = a³ + b³

Suy ra:

A³ + B³ = (A + B)(A² − AB + B²)

📌 Hằng đẳng thức thứ sáu

A³ + B³ = (A + B)(A² − AB + B²)

🔍 Ví dụ 1

Viết x³ + 1 dưới dạng tích:

x³ + 1

= x³ + 1³

= (x + 1)(x² − x + 1)

🔍 Ví dụ 2

Viết x³ + 8y³ dưới dạng tích:

x³ + 8y³

= x³ + (2y)³

= (x + 2y)(x² − 2xy + 4y²)

🔍 Ví dụ 3

Rút gọn:

(2x + 1)(4x² − 2x + 1) − 8x³

= (2x)³ + 1³ − 8x³

= 8x³ + 1 − 8x³

= 1

🔍 Ví dụ 4

Rút gọn:

(x + 4y)(x² − 4xy + 16y²) − x³ − 65y³

= x³ + (4y)³ − x³ − 65y³

= x³ + 64y³ − x³ − 65y³

= −y³

📖 2. Hiệu hai lập phương

Với hai số a và b bất kì:

a³ − b³ = (a − b)(a² + ab + b²)

Suy ra:

A³ − B³ = (A − B)(A² + AB + B²)

📌 Hằng đẳng thức thứ bảy

A³ − B³ = (A − B)(A² + AB + B²)

🔍 Ví dụ 5

Viết x³ − 27 dưới dạng tích:

x³ − 27

= x³ − 3³

= (x − 3)(x² + 3x + 9)

🔍 Ví dụ 6

Viết x³ − 8y³ dưới dạng tích:

x³ − 8y³

= x³ − (2y)³

= (x − 2y)(x² + 2xy + 4y²)

🔍 Ví dụ 7

Rút gọn:

(3x − 4)(9x² + 12x + 16) − 27x³

= (3x)³ − 4³ − 27x³

= 27x³ − 64 − 27x³

= −64

📖 3. Bảy hằng đẳng thức đáng nhớ

  • A² − B² = (A + B)(A − B)
  • (A + B)² = A² + 2AB + B²
  • (A − B)² = A² − 2AB + B²
  • (A + B)³ = A³ + 3A²B + 3AB² + B³
  • (A − B)³ = A³ − 3A²B + 3AB² − B³
  • A³ + B³ = (A + B)(A² − AB + B²)
  • A³ − B³ = (A − B)(A² + AB + B²)

📝 Ghi nhớ

  • Tổng hai lập phương được phân tích thành tích theo công thức: A³ + B³ = (A + B)(A² − AB + B²).
  • Hiệu hai lập phương được phân tích thành tích theo công thức: A³ − B³ = (A − B)(A² + AB + B²).
  • Bảy hằng đẳng thức đáng nhớ là công cụ quan trọng để biến đổi và rút gọn biểu thức.
  • Cần thuộc lòng các hằng đẳng thức để giải toán nhanh và chính xác.
