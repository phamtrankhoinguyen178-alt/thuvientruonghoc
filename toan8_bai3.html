📘 Bài 3: Phép cộng và phép trừ đa thức

📖 1. Phép cộng đa thức

Muốn cộng hai đa thức, ta nối hai đa thức bởi dấu "+" rồi bỏ dấu ngoặc và thu gọn đa thức nhận được.

🔍 Ví dụ 1

Cho:

A = 5x²y + 3x − 2

B = 2xy − 4x²y + 3x − 1

Tính A + B:

A + B = (5x²y + 3x − 2) + (2xy − 4x²y + 3x − 1)

= 5x²y + 3x − 2 + 2xy − 4x²y + 3x − 1

= (5x²y − 4x²y) + (3x + 3x) + (−2 −1) + 2xy

= x²y + 6x − 3 + 2xy

Vậy:

A + B = x²y + 2xy + 6x − 3

📖 2. Phép trừ đa thức

Muốn trừ hai đa thức, ta nối hai đa thức bởi dấu "−", bỏ dấu ngoặc rồi thu gọn đa thức nhận được.

🔍 Ví dụ 2

Tính A − B:

A − B = (5x²y + 3x − 2) − (2xy − 4x²y + 3x − 1)

= 5x²y + 3x − 2 − 2xy + 4x²y − 3x + 1

= (5x²y + 4x²y) + (3x − 3x) + (−2 + 1) − 2xy

= 9x²y − 1 − 2xy

Vậy:

A − B = 9x²y − 2xy − 1

📖 3. Tính chất của phép cộng đa thức

Phép cộng đa thức có các tính chất giống phép cộng các số.

📌 Tính chất giao hoán

A + B = B + A

📌 Tính chất kết hợp

(A + B) + C = A + (B + C)

Hay:

A + B + C = (A + B) + C = A + (B + C)

📖 4. Tìm đa thức chưa biết

Nếu:

A − B = C

thì:

A = B + C

Ngược lại, nếu:

A = B + C

thì:

A − B = C

🔍 Ví dụ 3

Cho:

M + 5x³y − xy² + 2y − 1 = x³y + 2xy² − 3y + 2

Tìm M.

Ta có:

M = x³y + 2xy² − 3y + 2 − (5x³y − xy² + 2y − 1)

= x³y + 2xy² − 3y + 2 − 5x³y + xy² − 2y + 1

= (x³y − 5x³y) + (2xy² + xy²) + (−3y − 2y) + (2 + 1)

= −4x³y + 3xy² − 5y + 3

Vậy:

M = −4x³y + 3xy² − 5y + 3

📝 Ghi nhớ

  • Muốn cộng hai đa thức, bỏ dấu ngoặc rồi cộng các hạng tử đồng dạng.
  • Muốn trừ hai đa thức, đổi dấu các hạng tử trong đa thức bị trừ rồi thu gọn.
  • Phép cộng đa thức có tính chất giao hoán và kết hợp.
  • Nếu A − B = C thì A = B + C.
  • Khi thu gọn đa thức, cần nhóm các hạng tử đồng dạng lại với nhau.
